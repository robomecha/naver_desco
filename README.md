# 네이버부동산 매물정리 표 (크롬 확장앱)

네이버페이 부동산(**fin.land.naver.com**)에서 매물 목록을 보는 동안, 매물 정보를 자동으로 모아
**주소 · 보증금/월세 · 매매금액 · 평단가 · 사용승인년도**가 담긴 표로 정리해 주는 크롬 확장 프로그램입니다.
CSV / 엑셀 / 클립보드로 바로 내보낼 수 있습니다.

## 표에 나오는 항목

| 항목 | 설명 |
|------|------|
| 주소 | 매물 소재지 |
| 종류 / 거래 | 아파트·상가·토지 등 / 매매·전세·월세 |
| 매매가 | 매매 매물의 가격 (예: `3억 5,000`) |
| 보증금 / 월세 | 전세·월세 매물의 보증금과 월세 |
| 평단가(만/전용평) | **매매·전세** 기준 자동 계산 |
| 평당월세(전용) | **월세** 매물의 평당 월세 (만원/평) |
| 면적(㎡/평) | 공급/전용(토지는 토지면적)과 평수 |
| 사용승인(년차) | 준공 후 경과 년차 (네이버 방식). 예: `19년차 (2008)` |
| 층 / 확인일 / 단지·건물 | 부가 정보 |
| 중복 | 같은 물건으로 합쳐진 매물 수 (예: `3건`) |

> 사용승인은 네이버가 제공하는 `approvalElapsedYear`(경과년차)를 우선 쓰고, 없으면
> 사용승인 연도에서 계산합니다(준공 연도를 1년차로 셈). 값이 비어 있으면
> **① 주소·사용승인 채우기** 버튼으로 상세를 불러오면 채워질 수 있습니다.

### 동일 매물 합치기

네이버는 **같은 물건을 여러 중개사가 각각 등록**해서 매물번호가 다른 중복이 많습니다.
`동일매물 1개만` 체크박스(기본 켜짐)를 켜면 아래가 **전부 같은** 매물을 한 줄로 합칩니다:

> 종류 · 거래유형 · 매매가/보증금/월세 · 면적 · 층 · 주소(없으면 단지·건물명)

합쳐진 개수는 **중복** 칸에 표시되고, 대표로는 **정보가 가장 충실한 매물**(주소·사용승인·층 등이
채워진 것)이 남습니다. 층이나 가격이 하나라도 다르면 **별개 매물로 유지**됩니다.
합치는 게 과하다 싶으면 체크박스를 끄면 원본 그대로 보입니다.

### 확인일 없는 조각 숨기기

지도 화면에서는 실제 매물 외에 **지도 마커·클러스터·초기 로딩 데이터** 같은 조각이 함께
잡혀 표에 섞일 수 있습니다. 이런 조각은 **확인일(매물 확인일자)이 없다**는 공통점이 있어서,
`확인일 없는 것 숨김` 체크박스(기본 켜짐)로 걸러냅니다. 숨긴 개수는 상단에 표시되며,
체크를 끄면 전부 보입니다. 특정 줄만 지우려면 맨 오른쪽 **✕** 를 누르세요
(같은 물건으로 합쳐진 중복까지 함께 삭제되고, 재스캔으로 되살아나지 않습니다).

### 현재 지역만 보기

네이버 페이지에는 **이전에 보던 지역·추천 단지** 데이터가 초기 로딩값으로 남아 있어,
지역을 옮겨도 다른 지역 매물이 몇 개 섞여 보일 수 있습니다. `현재 지역만` 체크박스(기본 켜짐)를
켜면 표에서 **가장 많은 지역(시·구)만 남기고** 다른 지역 매물을 숨깁니다. 감지된 지역은
체크박스 옆에 `(경기도 시흥시)` 처럼 표시됩니다. 두 지역 경계를 함께 보고 싶으면 체크를 끄세요.
(주소가 아직 안 채워진 매물은 판단할 수 없어 그대로 남습니다 — **①** 로 주소를 먼저 채우면 정확해집니다.)

### 현재 종류만 보기

지역과 마찬가지로, 검색과 무관한 **다른 종류 매물**(예: 토지를 검색했는데 끼어든 상가)이
섞일 수 있습니다. `현재 종류만` 체크박스(기본 켜짐)를 켜면 **가장 많은 종류만** 남기고
나머지를 숨깁니다. 감지된 종류가 옆에 `(토지)` 처럼 표시됩니다.
(종류 코드는 아파트=A01, 오피스텔=A02, 상가=D02, **토지=E03** 등으로 표시됩니다.)

> **평수·평단가·평당월세는 모두 전용면적 기준**입니다 (1평 = 3.305785㎡).
> 전용면적이 없으면 공급 → 토지 순으로 넘어가며, 면적칸에 어떤 기준인지
> `(전용 33.3평)` / `(토지 100.0평)` 처럼 표시됩니다.
> 월세는 평단가가 의미 없어 대신 **평당월세**를 계산합니다.

### 지번 주소 채우기 (카카오)

네이버부동산 목록은 주소를 **동(洞)까지만** 주고 세부 지번은 없습니다(좌표만 있음). 대신 매물마다
**위경도 좌표**가 있어서, 이를 카카오 지도로 역변환해 **지번 주소**를 채웁니다.

- 카카오 REST API 키는 이미 소스(`src/content.js`의 `DEFAULT_KAKAO_KEY`)에 넣어져 있고,
  **`지번 자동` 체크박스가 켜져 있으면 매물이 쌓일 때 지번이 자동으로 채워집니다.** (버튼 불필요)
- 즉시 채우고 싶으면 **🗺 지번 지금** 버튼을 누르면 됩니다.
- 좌표가 있는 매물의 주소가 `경기도 시흥시 장곡동 493-1` 처럼 지번까지 채워집니다.
- **같은 좌표는 한 번만 호출**해 모든 같은-좌표 매물에 적용합니다(캐시) → API 호출·할당량 절약.
- **정확도**: 목록 좌표는 대략치일 수 있어, 정확한 지번을 원하면 **① 사용승인 채우기**를 먼저 눌러
  상세의 정밀 좌표를 받은 뒤 지번을 채우세요.

**⚠ 카카오맵 API 활성화 필수**: 처음 쓸 때 `403` 이 뜨면, [developers.kakao.com](https://developers.kakao.com)
→ 내 애플리케이션 → 앱 → **카카오맵** → **사용 설정 ON** 을 해야 합니다(무료, 1회).
상단 상태줄에 `⚠지번 자동변환 중단` 이 뜨면 이 설정이 안 된 것입니다.

**📦 배포 시 주의**: 하드코딩된 키는 **모든 사용자가 공유**하므로 카카오 앱의 일일 할당량을
같이 씁니다(좌표 캐시 덕에 호출은 적음). 사용자가 많아질 것 같으면, 배포판에서 `DEFAULT_KAKAO_KEY`를
비워 각 사용자가 자기 키를 입력하도록(🗺 클릭 시 입력창) 바꾸는 것을 권장합니다.

> 키를 바꾸려면 `src/content.js`의 `DEFAULT_KAKAO_KEY` 값을 수정하면 됩니다.
> 키가 든 소스를 남에게 공유하면 키가 노출되니, 유출 시 카카오 콘솔에서 재발급하세요.
> (카카오 로컬 API는 무료 · 일 호출 한도 넉넉)

키 발급이 필요하면: [Kakao Developers](https://developers.kakao.com) → 내 애플리케이션 → 앱 만들기 → 앱 키 → REST API 키.

### 정렬

툴바의 `정렬:` 버튼으로 표를 다시 정렬합니다. **거래유형 세트**와 **층 세트**는 서로 독립적이라
**조합**할 수 있습니다 (같은 버튼을 다시 누르면 그 세트만 해제):

- 거래유형 세트 — **매매 / 전세 / 월세**: 해당 거래유형을 맨 위로 모읍니다
- 층 세트 — **1층순**(지하→1층→상층) / **상층순**(높은 층부터)
- 년차 세트 — **신축순**(사용승인 년차 적은 순) / **구축순**(년차 많은 순)

예) `매매 + 신축순` 을 함께 켜면 → 매매 매물이 먼저 오고, 그 안에서 신축(년차 적은 순)부터 정렬됩니다.

**층과 년차를 둘 다 켜면, 가장 최근에 누른 쪽이 우선**입니다. 예를 들어 `상층순`을 켠 상태에서
`신축순`을 누르면 → **년차(신축)가 우선**이 되고 층은 그 다음 기준으로 적용됩니다.
반대로 신축순 상태에서 상층순을 누르면 층이 우선이 됩니다.
(전체 우선순위: 거래유형 → [층·년차 중 최근 누른 것] → 나머지 하나 → 확인일. 정보 없는 매물은 항상 아래로.)

### 거래유형별 색상 & 자동 크기

- 행은 거래유형에 따라 **연한 파스텔톤**으로 구분됩니다 —
  매매(연파랑) · 전세(연초록) · 월세(연주황) · 단기임대(연보라). 상단 힌트줄에 색 범례가 있습니다.
- 패널은 **데이터 양에 맞춰 자동으로 크기가 조절**됩니다. 매물이 적으면 작게, 많으면 화면을
  꽉 채울 때까지 커지고(가로는 모든 열이 보이도록, 세로는 화면 높이까지), 화면을 넘으면
  패널 안에서 스크롤됩니다.

## 디스코(disco.re) 실거래 수집

같은 확장앱이 **www.disco.re** 에서도 동작합니다. 디스코에서 **필지·건물을 클릭할 때마다**
그 물건 자체의 정보(`short_info`)를 표에 모읍니다. (지도에 자동으로 뜨는 주변 유사거래·지역
최근실거래는 수집하지 않습니다 — **클릭한 것만**.)

- 표 항목: 거래일 · 주소(지번) · 건물명 · 종류 · **용도지역** · 지목 · 실거래가 · 평단가 · 면적 · 사용승인 · 층수
- 금액 단위는 **만원**. 실거래가는 디스코의 대표 실거래가(`price`)입니다.
- **용도지역**(제1종일반주거지역 등)·**지목**(대 등)이 포함됩니다.
- 종류: `토지`는 정확, 건물 종류(아파트/오피스텔 등)는 디스코 type 코드 기준의 잠정 매핑입니다.
- 디스코 주소엔 이미 지번이 있어 카카오 변환은 쓰지 않습니다.
- CSV·엑셀·복사·지도 JSON 내보내기 동일하게 동작합니다.

## 동작 방식

네이버는 공식 매물 API를 제공하지 않기 때문에, 이 확장앱은 **네이버 부동산 페이지가 스스로
호출하는 데이터 요청을 가로채(intercept)** 표로 정리합니다. 서버를 따로 두거나 크롤링하지 않으며,
여러분이 보고 있는 화면의 데이터만 사용합니다.

- 매물 목록을 스크롤하면 → 자동으로 표에 쌓입니다.
- **주소·사용승인년도**는 목록이 아닌 상세정보에 있으므로, 패널의 **① 버튼**을 누르면
  매물별 상세 API를 순차 호출해 채웁니다. (IP 차단 방지를 위해 약간의 간격을 두고 호출)

## 설치 방법 (개발자 모드)

1. Chrome 주소창에 `chrome://extensions` 입력 후 이동
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 폴더(`네이버부동산매물정리`)를 선택
5. `fin.land.naver.com` 에 접속하면 오른쪽 아래에 **🟢 매물정리** 버튼이 나타납니다.

## 사용법

1. [네이버페이 부동산](https://fin.land.naver.com/) 에서 원하는 지역/단지의 매물 목록을 엽니다.
2. 목록을 스크롤하면 오른쪽 아래 버튼의 숫자가 올라갑니다(수집된 매물 수).
3. **매물정리** 버튼을 눌러 표 패널을 엽니다.
4. **① 주소·사용승인 채우기** 를 눌러 주소/사용승인년도를 채웁니다.
5. **CSV / 엑셀 / 복사** 로 내보냅니다. (엑셀·복사는 붙여넣기용 표 형식)

## 참고 / 한계

- 네이버가 페이지 구조나 데이터 필드명을 바꾸면 일부 항목이 비어 보일 수 있습니다.
  이 경우 패널의 **🐞 진단복사** 버튼으로 실제 데이터 구조를 덤프해서
  `src/content.js` 의 `normalize()` 매핑에 반영하면 됩니다.
- 참고로 fin.land 는 매물번호가 `articleNumber`, 가격이 `priceInfo{dealPrice, warrantyPrice,
  rentPrice}`(**단위 원**), 면적이 `spaceInfo{supplySpace, exclusiveSpace, landSpace}`(㎡),
  **사용승인일은 매물이 아닌 단지(complex) 객체의 `useApprovalDate`** 에 들어 있습니다.
- 상세정보(주소·사용승인) 보강은 현재 `fin.land.naver.com` 기준으로 동작합니다.
- 과도한 상세 호출은 네이버의 일시적 IP 제한을 유발할 수 있으니, 한 번에 너무 많은 매물을
  보강하지 않는 것을 권장합니다.
- 개인 용도의 데이터 정리를 위한 도구이며, 대량 수집·재배포 용도가 아닙니다.
