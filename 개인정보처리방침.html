개인정보처리방침

네이버부동산·디스코 매물정리 (크롬 확장 프로그램) · 시행일 2026년 7월 24일

1.요약

이 확장 프로그램은 회원가입·로그인이 없고, 별도의 수집 서버를 운영하지 않습니다. 사용자가 보고 있는 네이버부동산·디스코 페이지가 자체적으로 불러오는 공개된 부동산 매물·실거래 정보(주소, 가격, 면적, 층, 사용승인일 등)를 브라우저 안에서만 정리해서 보여주며, 이 데이터는 브라우저 메모리에만 저장되어 새로고침하면 사라집니다. 이름·연락처·로그인 계정 같은 개인 식별정보는 수집하지 않습니다.

2.수집하는 정보

2-1. 매물·실거래 정보 (부동산 공개정보)

다음 사이트에 접속해 있는 동안, 그 페이지가 스스로 서버에 요청해서 받아오는 응답을 가로채(intercept) 표로 정리합니다. 확장앱이 별도로 어딘가에 요청을 보내 데이터를 긁어오지 않으며, 사용자가 실제로 보고 있는 화면의 데이터만 처리합니다.

대상 사이트fin.land.naver.com, new.land.naver.com, disco.re
수집 항목매물 주소, 종류, 거래유형(매매/전세/월세), 가격, 면적, 층, 사용승인년도, 용도지역, 지목, 좌표(위경도) 등 — 모두 해당 부동산 사이트가 공개적으로 제공하는 정보입니다.
수집 방식페이지가 자체적으로 호출하는 fetch/XHR 응답을 콘텐츠 스크립트가 읽어들임 (네트워크 요청을 새로 만들지 않음). 네이버는 매물 목록을 스크롤할 때, 디스코는 필지·실거래 항목을 클릭할 때 정리됩니다.
저장 위치브라우저 탭의 자바스크립트 메모리(변수). 디스크나 서버에 저장하지 않으며, 페이지를 새로고침(F5)하거나 탭을 닫으면 사라집니다. "초기화" 버튼으로 언제든 즉시 삭제할 수 있습니다.

2-2. 확장 프로그램 설정 (브라우저 로컬 저장)

카카오 지도 API를 이용한 지번(주소) 변환 기능을 위해, 아래 정보만 chrome.storage.local (이 브라우저 안에만 저장되는 공간)에 저장될 수 있습니다.

  • 카카오 REST API 키 — 사용자가 직접 입력하거나, 기본 제공 키가 사용됩니다. 좌표↔주소 변환 요청 시에만 쓰입니다.

이 값은 이 브라우저에만 남아 있으며, 확장 프로그램을 삭제하면 함께 삭제됩니다.

2-3. 수집하지 않는 정보

  • 이름, 이메일, 전화번호, 로그인 계정 등 개인 식별정보
  • 결제·금융 정보
  • 방문 기록, 검색어, 위치정보(사용자의 실제 위치) — 매물 좌표만 다룰 뿐, 사용자 GPS 위치는 사용하지 않습니다.
  • 쿠키 기반 추적, 광고 식별자, 사용통계(analytics)

3.제3자 제공 및 외부 전송

확장 프로그램 개발자가 운영하는 서버는 없으며, 수집된 매물 데이터는 외부로 전송되지 않습니다. 다만 아래 한 가지 기능에 한해 카카오(Kakao) 서버와 통신합니다.

지번 변환(좌표 ↔ 주소, 카카오 로컬 API)

매물의 위경도 좌표 또는 주소를 dapi.kakao.com 으로 전송해 지번 주소를 받아옵니다. 이 통신은 카카오의 API를 그대로 이용하는 것으로, 전송되는 정보는 좌표·주소 문자열뿐이며 사용자를 식별할 수 있는 정보는 포함되지 않습니다. 이 과정에는 카카오의 개인정보처리방침이 적용됩니다.

그 외에는 어떤 정보도 제3자에게 제공·판매·공유하지 않습니다.

4.내보내기(다운로드) 기능

정리한 표는 사용자의 선택에 따라 CSV, 엑셀(.xls), 지도 연동용 JSON 파일로 사용자의 컴퓨터에만 저장됩니다. "복사" 기능도 사용자의 클립보드에만 복사되며, 이 과정에서 어떤 데이터도 외부로 전송되지 않습니다.

5.요청 권한과 사용 목적

host_permissionsfin.land.naver.com, new.land.naver.com, disco.re, dapi.kakao.com — 매물 데이터 읽기 및 지번 변환 API 호출에 사용됩니다.
storage카카오 API 키를 이 브라우저에 저장하기 위해 사용됩니다.
clipboardWrite"복사" 버튼으로 표 내용을 클립보드에 복사하기 위해 사용됩니다.

6.보관 기간 및 삭제

  • 매물·실거래 데이터: 브라우저 메모리에만 존재 — 새로고침·탭 종료 시 자동 삭제, "초기화" 버튼으로 즉시 삭제 가능
